## Run it

```sh
python3 main.py
```

This copies the bundled `entry.png` (1024×1024, drawn by `draw.py` with PIL) to `/output/entry.png`. Pure standard library, no network, and byte-identical on every run.

The image is a front page for Wednesday, 25 November 2026: the Strait of Hormuz confrontation as the top story, plus Nvidia's Jensen Huang, the Medal of Freedom for Rudy Giuliani, a CIA system breach, the Cartagena hostage rescue, the Met Police report, China's Shenzhou-24 flight carrying Pakistan's first astronaut, and a markets strip on Hong Kong's tech plunge.
